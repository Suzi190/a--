🖼️ 图片识别功能测试

功能说明

本次更新实现了以下功能：

  • ✅ 图片自动压缩（超过指定大小自动压缩）
  • ✅ 图片发送流畅性优化（后台异步处理）
  • ✅ 闪退防护（内存监控、错误捕获）
  • ✅ 图片识别结果本地缓存
  • ✅ AI调用时优先使用已识别的文本

数据结构示例

{ "sender": "user", "content": "[图片]", "timestamp": 1234567890, "chatId": 1, "fileName": "photo.jpg", "imageData": "data:image/jpeg;base64,...", "displayImageData": "data:image/jpeg;base64,...", "imageText": "图片中包含一只橘色的猫，正在阳光下打盹...", "imageRecognized": true }

测试步骤

  1. 打开主应用（index.html）
  2. 进入任意聊天界面
  3. 点击+号，选择"相册"
  4. 选择一张图片发送
  5. 观察控制台输出（F12打开开发者工具）
  6. 等待几秒后，点击爱心按钮调用AI
  7. AI应该能看到图片的识别内容

预期行为

发送图片时：
1. 图片立即显示在聊天界面
2. 控制台显示"【图片】原始大小: X KB"
3. 控制台显示"【图片】压缩后大小: X KB"
4. 控制台显示"【图片识别】开始识别图片..."
识别完成后：
1. 控制台显示"【图片识别】识别完成并缓存: ..."
2. 数据已保存到本地存储
调用AI时：
1. 控制台显示"【图片消息】使用已识别的图片文本: ..."
2. AI能看到图片的具体内容描述

控制台日志关键词

在浏览器开发者工具（F12）的控制台中搜索以下关键词查看相关日志：

  • 【图片】 - 图片压缩相关日志
  • 【图片识别】 - 图片识别相关日志
  • 【图片消息】 - AI调用时图片处理日志

故障排查

如果图片没有识别：
1. 检查是否配置了API密钥
2. 检查网络连接
3. 查看控制台是否有错误信息
如果AI看不到图片内容：
1. 确认图片已经识别完成（imageRecognized: true）
2. 检查imageText字段是否有内容
3. 重新进入聊天界面再试
